Bifrost keeps the human in control of AI website generation Bifrost：让人类始终掌控 AI 建站过程

① Proposal–Confirm–Intervene

AI proposes, you confirm. Nothing is final until you say yes. AI 先提议，你再确认。没有你的同意，任何东西都不会被定稿。

② Bounded Control Authority

Freedom to create, inside safe constraints — the Freedom–Constraint Paradox. 在可控边界内自由创作 —— 自由与约束的平衡。

③ Visual PPT-style Skeleton

No blank canvas. AI draws an editable sketch you recognise. 告别空白画布。AI 先画出你能直接修改的可视化草图。

④ Transparent & Verifiable

You can preview the real HTML and compile step by step — trust comes from seeing, not believing. 你能预览真实 HTML、一步步编译。信任来自“看见”，而不是“相信”。

🎬 Demo Script — Bifrost Chat

  1. Type the prompt “I want a coffee shop website called Brew & Co — a hero, a menu, and a contact form.” 输入：「我要一个咖啡店网站，叫 Brew & Co，要有首屏、菜单和联系表单。」

  3. Show the structured proposal appear (blocks, not a full page) “You see a skeleton you can already read and steer.” 你会看到一个你能读懂、能引导的草图骨架。

🎬 Demo Script — Bolt.new (2nd screen)

  1. Open bolt.new, paste the SAME prompt “Same words. Watch what Bolt gives back.” 同样的句子，看看 Bolt 返回什么。
  2. Point at the instant full site “Bolt is fast — but the structure is fixed. Hard to change one piece.” Bolt 很快，但结构是固定的，很难单独改一块。
  3. Alt-Tab back to Bifrost “Back to Bifrost — where YOU stay the author.” 切回 Bifrost —— 在这里你始终是作者。
💡 HCI insight (you may have missed this): The real differentiator is not speed, it is reduced blank-page anxiety + intent clarification. A recognised skeleton lowers cognitive load and makes the user feel agentic from second one. Bolt optimises for output speed; Bifrost optimises for user agency. 真正的差异不是速度，而是降低“空白页焦虑”+澄清意图。可识别的草图降低认知负荷，让用户从第一秒就有掌控感。

⏱ ~3 min PAGE 3 · PROPOSAL STAGE · EDIT ELEMENTS
Proposal: add / delete / modify — every step confirmed 提案阶段：增 / 删 / 改，每一步都确认

🎬 Demo Script — edit elements

  1. Double-click the hero title → change text live “Edit text directly on the canvas — WYSIWYG.” 直接在画布上改文字，所见即所得。
  2. Drag a block to move it; pull the corner handle to resize “Move and resize — the layout follows your hand.” 拖动移动、拉角缩放，布局跟着你的手走。
  3. Click a block → red × button appears → delete it “One click to remove — reversible, low cost.” 一键删除，可撤销，试错成本低。
  4. Open Properties panel → “Add block” → add a Testimonials card “Add a new piece from the panel — it syncs to the canvas instantly.” 从属性面板加新模块，立刻同步到画布。

🎬 Demo Script — confirm & sync

  1. Make a change in AI Chat (right panel) → watch canvas update “Chat edits and canvas stay in sync — no hidden state.” 对话里的修改和画布实时同步，没有隐藏状态。
  2. Show the “Compile” gate is NOT yet pressed “Nothing is locked in. You confirm before we compile.” 一切都还没锁定，编译前由你确认。
  3. Point at each element’s confirm state “Every element is something you agreed to.” 每个元素都是你同意过的。
💡 HCI insight (proactive): Three principles on display — (1) reversible actions lower the fear of breaking things; (2) immediate WYSIWYG feedback closes the action–result loop; (3) discoverable controls (the × button, corner handles) mean the user never has to guess. This is Bounded Control Authority in practice: free to change anything, but the system never changes it for you silently. 可撤销、即时反馈、可发现的控件 —— 这就是“有边界的控制权”：你可以改任何东西，但系统绝不会偷偷替你改。

⏱ ~4 min PAGE 4 · EDIT STAGE · PREVIEW → COMPILE → DEPLOY
Edit: preview the real HTML, then compile & ship 编辑阶段：先看真实 HTML，再编译、上线

🎬 Demo Script — Preview & AI add

  1. In Edit, click “👁 Preview HTML” “See the actual generated page — not a mock-up.” 看到真实生成的页面，不是假图。
  2. Use right-side AI Chat → “add a dark-mode toggle” “Add features by chat, then preview again.” 用右侧对话加功能，再预览一次。
  3. Upload an image via the 📁 button (demo data-URI embed) “Images embed as data — they survive Deploy.” 图片以 data URI 内嵌，部署后依然显示。

🎬 Demo Script — Compile & Deploy

  1. Click “Compile” → status: Compiling → Compiled “Retry logic means it never sticks on Error.” 重试机制保证它不会卡在 Error。
  2. Compile all slides until “X/X compiled” “Every slide confirmed before we ship.” 每个页面都确认了才上线。
  3. Click “🚀 Deploy” → live preview shows full site WITH images “The human is the final gate. Done.” 人类是最后一道关卡。完成。
💡 HCI insight (proactive): Transparency builds trust. The Preview-HTML button turns a black box into a glass box; the visible Compiling→Compiled state gives feedback on system progress; and Deploy only runs after you confirm every slide. That is control authority made observable — the examiner sees exactly where the human’s authority lives. 透明建立信任。Preview 把黑盒变玻璃盒；编译状态给出系统进度反馈；部署前由你逐页确认 —— 控制权变得“可见”。
