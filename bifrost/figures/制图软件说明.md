# 制图软件说明

本论文所有实证图表均使用 **Python matplotlib 绘图库**以编程方式生成，不使用任何商业制图或排版软件手动绘制。

## 软件信息

| 项目 | 说明 |
|------|------|
| 软件名称 | matplotlib（Python 开源绘图库） |
| 运行环境 | Python 3.13 + matplotlib 3.x |
| 输出分辨率 | 300 DPI（满足学位论文印刷要求） |
| 字体规范 | 统一 Times New Roman，符合 APA / 学术出版格式 |
| 生成脚本 | `scripts/gen_thesis_figures.py` |
| PDF 嵌入 | 使用 PyMuPDF 将图表按原位置覆盖进论文 PDF |

## 为什么用 matplotlib 而不是手工制图

1. **数据驱动**：图表数值直接读取实验统计结果（均值、标准差、效应量 d、p 值），图文与正文严格一致，不会出现手绘误差。
2. **可复现**：修改数据源后一行命令即可重新渲染全部配图，便于导师或审稿人复核。
3. **矢量级清晰度**：300 DPI 输出在印刷与屏幕上均清晰，优于截图或 PPT 导出。
